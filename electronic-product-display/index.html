About Electronic Product Display System

This Web Technology Mini Project demonstrates modern client-side frontend engineering principles without relying on heavy third-party JavaScript frameworks. Built purely using standard semantic HTML5, CSS3 Glassmorphic Design, and modular Vanilla JavaScript.

🔍

Dynamic Multi-Filtering

Filter products seamlessly across 8 electronic categories, execute instant sub-string searches, and sort catalog items by price or rating in real-time.

📋

Detailed Specifications Modal

Each product card features an interactive modal pop-up detailing comprehensive hardware specifications, stock status, and buyer review ratings.

🛒

Persistent Shopping Cart

Integrated side-drawer cart system using browser LocalStorage API. Add items, adjust quantities, calculate total bill, and trigger simulated checkouts.
